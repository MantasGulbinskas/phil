**Root cause:** re-checking a "best-of-N-labs" leaderboard market by
re-verifying only the previously-identified top rivals, rather than
re-scanning the current top of the board for a new entrant. The market
family runs several parallel per-lab questions (Alibaba, Xiaomi, OpenAI,
Anthropic all resolve off the same arena.ai table) but nothing cross-
references a new leader found on one lab's forecast against still-open
estimates on the sibling legs.

**Fix applied to `strategy/playbook.md`** (added under the resolver-
process / leaderboard section, near the arena.ai source-reading rule): on
every re-check of an arena.ai (or similar N-lab leaderboard) market, scan
the current top rows of the board fresh rather than only the previously-
named rivals — a new entrant between checks is exactly what a repeated
partial re-check misses — and when a sibling per-lab forecast on the same
underlying board reads a different leader, treat that as a flag to
re-check any other still-open forecast on that board before it settles.
